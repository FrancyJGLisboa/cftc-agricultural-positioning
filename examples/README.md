# Output examples

These are unedited PNG/PDF pairs generated by CFTC Agricultural Positioning edition 2.0.0, methodology 3.0, during tests on September 11, 2026. All four show positions as of September 8, 2026. They are static documentation examples, not a live feed or synthetic market data.

| Files | Category | View | How generated |
| --- | --- | --- | --- |
| managed-money-overview.png / .pdf | Managed Money | 13-market summary, contracts | Live CFTC retrieval |
| soybeans-mmt.png / .pdf | Managed Money | Soybean detail, MMT | Live CFTC retrieval |
| corn-pct-oi.png / .pdf | Managed Money | Corn detail, percent of OI | Offline reproduction of a saved official snapshot |
| legacy-overview.png / .pdf | Legacy Non-Commercial | 13-market summary, contracts | Offline reproduction of a saved official snapshot |

Source datasets: [CFTC Disaggregated Futures Only](https://publicreporting.cftc.gov/Commitments-of-Traders/Disaggregated-Futures-Only/72hh-3qpy) and [CFTC Legacy Futures Only](https://publicreporting.cftc.gov/Commitments-of-Traders/Legacy-Futures-Only/6dca-aqww). Position dates and publication dates are distinct. Do not combine the categories.

The [main README](../README.md#example-prompts-and-outputs) pairs each image with a hypothetical English prompt for a live run of that view. Those prompts are not transcripts of the original test runs and do not guarantee these historical values on a later run. To reproduce a specific saved snapshot, explicitly request offline reproduction and supply the corresponding official source JSON, as described in the main README.

[manifest.json](manifest.json) records SHA-256 hashes of each published PNG and PDF. The pairs were checked against the original validation hashes or retained test records before inclusion. Raw snapshots, delivery state and private execution logs are not included here. Both pages and units were checked during the original trials; these assets preserve those outputs, including the repeated net/OI indicator in the current corn layout.

These files are repository documentation assets. The bundled repository exporter creates a base repository from the installed skill; this gallery lives outside the installable skill folder and must be retained when updating an existing repository from a fresh export.
